### MCP 调用形状（踩过坑，照抄）
```powershell
# 执行 C#（必须 action + code + safety_checks:false）
mcp_call.ps1 -Tool execute_code -Args '{"action":"execute","code":"...","safety_checks":false}'
# 菜单（只传 menu_path）

mcp_call.ps1 -Tool read_console -Args '{"action":"get","types":["error","warning"],"count":50}'
```

### 强制 Unity 重新编译（否则静默跑旧 DLL）
`refresh_unity` 不一定重编。可靠配方：C# `Codedom` 触发 `UnityEditor.Compilation.CompilationPipeline.RequestScriptCompilation()` → 等 → `AssetDatabase.ImportAsset(..., ForceUpdate)` → 用反射确认新字段存在 + 读 `Assembly-CSharp.dll` 写时间。
**`check.ps1` 绿只证明 MSBuild 能编，不证明 Unity 加载了新代码。**

### 截图（Unity）
`Camera.Render()` 到 `RenderTexture` → `ReadPixels` → `EncodeToPNG`。
**不要用 `ScreenCapture.CaptureScreenshot`**（拍上一帧，常拍到空场景）。
Play 前把 `KingdomWeather.hoursPerSecond = 0` 并 `SetHour(9)`，否则几分钟后入夜全黑。

### 3.3 统一契约（所有模块必须遵守）
```python
build(kind, MAT, rng, at=None, rz=0.0, **kw) -> list[obj]   # 原点在占地中心，+Y 为正面，地面 z=0
footprint(kind) -> (x, y)                                    # 实测占地
MAT_KEYS = (...)                                             # 35 键，缺键由 make_materials() 自愈
if __name__ == "__main__": preview()                         # 自己出 3 视图
```
`at=` 会把变换**烘进 mesh**，对象矩阵保持单位阵（便于合并/实例化）。
**1 unit = 1 m。** 禁止缩放整件物品来"适配"。

## 5. 我自己看出来的四个"玩具感"来源（已下达，未验收）

1. **配色**：屋顶高饱和红+艳蓝交替、墙面纯白 → 要赤陶 62% / 石板灰 24% / 深褐苔绿 10% / **蓝瓦 ≤4% 且只许 core 区**；墙 灰泥45/石材30/土坯15/白灰≤12%
2. **铺装过量**：灰色比房子占地还多 → 铺装只留街道走廊 + 门前 2–3 m
3. **没有阴影**：太阳角压到 28–42°、开 shadow + 接触阴影
4. **城堡蘑菇盘** + **城内一棵树都没有**

## 7. 坑（新增，接 AI_HANDOFF.md 那 15 条之后）

1. **FBX 轴**：Unity 导入要注意 `materialImportMode = ImportStandard`，否则材质全丢
2. **Unity 不重编**：`check.ps1` 绿 ≠ Unity 加载新代码（见 §2）
3. **PowerShell 写文件会毁中文**：`Set-Content -Encoding UTF8`（PS5.1）→ cp936 误读、**吞换行**，一次性损坏两个 900 行的 C# 文件。**任何文本改写用 Python `rb`/`wb`**
4. **`H.apply(parts[-len(parts):], T)` 会复合位移**，且 `barbican` 曾 `parts += parts` 把全套复制、min z 浮到 0.7
5. **`hd_common.roof` 的老问题**：瓦垄是通长板条（0.06 m 通缝 = 17.6%），山墙端 `end_mat` 不传会回落成木色 → `hd_castle.py:372` 的 `tiled_roof()` 是正解，尚未移植回 `hd_common`
6. **Blender 5.2 合成器 API 变了**：`scene.node_tree` 不存在 → `scene.compositing_node_group`；`CompositorNodeComposite` 已删
7. **`sky.sky_type="NISHITA"` 在 5.2 抛 TypeError**，被 `except: pass` 吞掉后整条大气链路静默失效
8. **不要把"看起来悬空"当"真的悬空"**：先量坐标，再改几何（46 块脊饰那次是真悬空）
9. **`--hd` 关掉时旧路径必须一行不变**（向后兼容的硬要求）
